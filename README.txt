Petrichor v0.1.0 — Reflexed
Generative synthesizer of natural phenomena: dew drops, canopy, wind, soil, thunder.

INSTALL
-------
Windows: copy "Petrichor.vst3" to
  C:\Program Files\Common Files\VST3\
macOS: copy "Petrichor.vst3" to
  /Library/Audio/Plug-Ins/VST3/   (system-wide)
  ~/Library/Audio/Plug-Ins/VST3/  (per-user)
Linux: copy "Petrichor.vst3" to
  ~/.vst3/

The plugin plays by itself as soon as it loads. It adapts to the host key and
tempo; without a host it free-runs at 70 BPM. Sidechain input "Pocket" ducks
the DEW and BREEZE buses from 1.5-4 kHz in the source signal.
